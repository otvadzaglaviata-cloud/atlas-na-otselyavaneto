# АТЛАС НА ОЦЕЛЯВАНЕТО 0.1.0

Първа публична версия за Windows.

## Какво има

- Всички обекти в 8 слоя: вода, убежища, болници, аптеки, храна, хижи, гориво и
  зарядни станции — 19 781 точки.
- Базовата карта е вградена в инсталатора; приложението работи офлайн веднага.
- Филтри по категория, търсене по име, общ брой обекти.
- Детайли при клик с координати и бутон за копиране.
- Тъмна карта с надписи на населените места.

## Инсталация

1. Свали `Atlas-0.1.0-x64-setup.exe`.
2. При SmartScreen: **More info → Run anyway** (инсталаторът е неподписан).
3. Next → Install. Инсталира се за текущия потребител, без админ.

Windows 10/11 x64. Размер ~88 MB. След инсталация не е нужен интернет.
